# Deployments

This folder contains project-based deployment notes and lightweight
configuration. It mirrors the blog post slugs under `architectures/` when a post
has deployment context.

Example:

```text
architectures/00-setup/README.md
deployments/00-setup/README.md
```

Deployment folders are not required for every post. Add one when a post needs
repeatable setup notes, environment examples, operational notes, or references
to the workflow used to ship it.
